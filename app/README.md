# Interface do SGA

Responsável: Leo

- **Linguagem:** a definir (qualquer uma, **exceto PHP**)
- **Regra:** toda comunicação com o banco via Stored Procedures e Views (sem SQL cru)

## Requisitos da interface

- Tela de login (usa `sp_LoginUsuario` com a senha já em hash)
- Controle de acesso por perfil: Secretário × Coordenador
- Telas: cadastro de alunos, matrícula, lançamento de notas, boletim/histórico, relatórios
